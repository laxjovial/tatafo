# Pages (`src/pages`)

This directory contains the top-level React components that correspond to the different pages or routes of the application. Each component in this directory is typically associated with a specific route in the `App.jsx` file.

Pages are responsible for fetching data and composing a UI from the reusable components found in the `src/components` directory.

## Pages

*   **`AIAssistantPage.jsx`:** The page for the AI assistant.
*   **`AdminDashboardPage.jsx`:** The page for the admin dashboard.
*   **`ChangePasswordPage.jsx`:** The page for changing the user's password.
*   **`DashboardPage.jsx`:** The main dashboard page for authenticated users.
*   **`ForgotPasswordPage.jsx`:** The page for requesting a password reset.
*   **`IntegrationsPage.jsx`:** The page for managing third-party integrations.
*   **`LoginPage.jsx`:** The user login page.
*   **`RegisterPage.jsx`:** The user registration page.
*   **`ResetPasswordPage.jsx`:** The page for resetting the user's password with a token.
*   **`SubscriptionPage.jsx`:** The page for managing the user's subscription.
*   **`UserProfilePage.jsx`:** The page for viewing and editing the user's profile.
