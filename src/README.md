# Frontend Source Code (`src`)

This directory contains all the source code for the React frontend of the Intelli-Agent application.

## Subdirectories

*   **[assets](assets/README.md):** Static assets like images and icons.
*   **[components](components/README.md):** Reusable React components that are used across multiple pages.
*   **[hooks](hooks/README.md):** Custom React hooks that encapsulate business logic and state management.
*   **[pages](pages/README.md):** Top-level components that correspond to the different pages or routes of the application.
*   **[services](services/README.md):** Modules for interacting with external APIs and services, such as Firebase and analytics.
*   **[styles](styles/README.md):** Global CSS styles and variables.
*   **[utils](utils/README.md):** Utility functions that can be used throughout the application.

## Main Files

*   **`App.jsx`:** The main application component, which sets up the routing for the application.
*   **`index.js`:** The entry point for the React application, which renders the `App` component into the DOM.
*   **`config.js`:** Centralized configuration for the frontend, such as API base URLs.
